# Hadith Nawawi Example

A simple example application demonstrating how to use the Hadith Nawawi package.

## Features

- Display a list of all hadiths from the Nawawi collection
- Search functionality to find specific hadiths
- Detailed view of each hadith with Arabic and English text
- Information about the collection

## Getting Started

1. Ensure you have Flutter installed on your machine
2. Clone the repository
3. Run `flutter pub get` to install dependencies
4. Run `flutter run` to start the application

## Usage

This example demonstrates:

- How to load hadiths from the package
- How to display hadiths in a list
- How to search through hadiths
- How to show detailed information about a hadith
